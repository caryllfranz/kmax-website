# KMAX Fitness

The public KMAX landing page is built with Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui, and Lucide icons.

## Preview locally

Install the project dependencies if they are not already installed, then run:

```bash
npm install
npm run dev
```

Open http://localhost:3000.

The landing page uses the supplied KMAX logo, the November 2026 class graphic as a historical reference, and the provided 10th Anniversary Fun Run details. Class and fun run registration enquiries go through KMAX's Facebook page or Messenger; the website does not collect registrations. The map and review link point to the KMAX Fitness Gym Google Maps listing at 57 King Christian Ext, Novaliches, Quezon City.

Confirm the current class schedule, membership details, event time, and any review text with KMAX before publishing.
